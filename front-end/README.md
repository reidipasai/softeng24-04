# Frontend documentation

Our frontend is based on streamlit, a data analysis framework. Streamlit has become an excellent choice for such applications, thus, we chose to work with it
for this one. To run our GUI, you have to make sure you have streamlit installed and then:
```bash
streamlit run home.py
```

Once you do this, our GUI will appear on your localhost. In order for the operations to work, the backend needs to be up as well. Make sure you read [back-end documentation](../back-end/README.md)
as well.
